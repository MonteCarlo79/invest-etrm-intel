## 学习目标

- 阐述实物期权观点：运营与投资灵活性是一组针对实物资产的期权，应以期权逻辑而非静态净现值定价。
- 列举发电领域的标准实物期权（运营/调度、启停切换、投资/推迟、封存、扩张、燃料切换），并为每项指出触发变量。
- 解释为何静态净现值低估灵活性资产的价值，并计算经期权调整后的投资门槛。
- 在二叉树上求解一个小型投资时机问题，并诠释"等待溢价"。

## 直觉理解

静态净现值的规则是：当预期折现现金流超过成本时则建设。该规则将决策视为"现在或永不"。但开发商可以*等待*：若电价上涨，项目价值提升；若电价下跌，开发商只需不建即可。未来建设的权利——无需承担义务——是一个针对项目价值的美式看涨期权。持有土地、并网许可或审批文件，即是持有该期权。

同样的逻辑贯穿电厂的整个生命周期：一旦建成，运营商持有以下期权：运行（调度）、停机并重启（切换，需支付启动成本）、封存、扩容或切换燃料。上述每种灵活性都有各自的触发条件（某个价差、价格水平或需求门槛）以及静态分析所忽略的价值。实物期权框架是总体方法：枚举所有灵活性，识别各自的触发条件，将每项灵活性作为期权进行估值，再与静态净现值相加。

## 正式处理

**投资时机（典型问题）。** 项目价值 $V$ 遵循扩散过程（例如，漂移率为 $\mu$、波动率为 $\sigma$ 的几何布朗运动）；建设成本 $I$ 固定；建设期权为永续美式期权，收益为 $V - I$。在标准假设下（Dixit–Pindyck），最优规则为：当 $V$ 首次达到以下水平时建设：

$$V^* = \frac{\beta_1}{\beta_1 - 1} \cdot I, \qquad \beta_1 = \tfrac12 - \frac{\mu - \delta}{\sigma^2} + \sqrt{\left(\tfrac12 - \frac{\mu-\delta}{\sigma^2}\right)^2 + \frac{2r}{\sigma^2}} > 1$$

其中 $\delta$ 为便利收益率/现金流派发率，$r$ 为无风险利率。乘数 $\beta_1/(\beta_1 - 1) > 1$ 即为**等待溢价**：期权性将建设触发门槛推高至*超过*静态净现值盈亏平衡点 $V = I$——通常达到成本的1.5至2倍。在静态净现值等于零时建设，会损耗等待期权的价值。

**发电资产的实物期权分类：**

| 实物期权 | 触发变量 | 典型持有方 |
|---|---|---|
| 运营 / 调度 | 小时级清洁火花价差 > 0（加摊销启动成本） | 运营商 |
| 启停切换 | 价差与启动成本及最短运行经济性之比较 | 运营商 |
| 投资 / 推迟 | 长期利润空间与建设成本 × 等待乘数之比较 | 开发商 |
| 封存 / 重启 | 固定运维成本与预期利润空间之比较 | 所有者 |
| 扩容 / 改造 | 增量容量上的利润空间 | 所有者 |
| 燃料切换 | 燃料A与燃料B的清洁火花价差之比较 | 双燃料运营商 |

每一行均代表一种实物期权框架可量化、而静态模型将其设为零的灵活性。

**求解方法。** 永续问题存在解析解（如上所述）；有限期限或路径依赖问题可采用二叉树/三叉树（对价格过程进行矩匹配——参见本课程来源中的格子模型材料）、带回归的蒙特卡洛方法（LSM，下一概念）或基于调度模型的动态规划。

## 例题

项目：以 $I = 1$ 亿欧元建设一座调峰电厂。项目价值 $V$（若今日建设，整个生命周期利润空间的净现值）服从几何布朗运动，参数为 $\mu - \delta = -0.04$，$\sigma = 0.25$，$r = 0.05$。

$$\beta_1 = \tfrac12 - \frac{-0.04}{0.0625} + \sqrt{\left(\tfrac12 - \frac{-0.04}{0.0625}\right)^2 + \frac{2 \times 0.05}{0.0625}} = 1.14 + \sqrt{1.30 + 1.60} = 1.14 + 1.70 = 2.84$$

等待乘数：$\beta_1/(\beta_1 - 1) = 2.84/1.84 = 1.54$。建设触发门槛：$V^* = 1.54$ 亿欧元——静态净现值规则在1亿欧元时建设；期权逻辑要求等待直至项目价值看起来比成本高54%。当 $V = 1.1$ 亿欧元时，静态分析师选择建设并放弃期权；推迟期权的价值等于继续持有与提前行权之间的差额，可通过实验中的二叉树加以量化。

`labs/real_options_framework_for_generation_assets/compute.py` 计算 $\beta_1$、触发门槛以及有限期限建设期权的200步二叉树价值；测试断言闭合解析解的数值正确，并验证随着期限延长，树的计算结果收敛于解析解。

## 市场差异

- **欧盟/英国：** 容量市场收益改变了派发率 $\delta$（更稳定的现金流降低等待溢价）；并网连接排队使*并网协议本身*成为一种稀缺的推迟期权，供开发商交易。
- **美国：** 投资税收抵免（ITC）/生产税收抵免（PTC）的作用类似于具有法定到期日的 $I$ 或 $\delta$ 的变化——这是一个有明确截止期限的期权，临近到期时会压缩等待溢价（引发"年底前建设"的赶工潮）。
- **中国：** 投资更多依赖行政安排而非期权逻辑（核准、指标），因此该框架的解读有所不同：推迟期权部分归属于规划方而非开发商。然而，对于136号文之后的市场化新能源/储能项目，收益不确定性是真实存在的，投资/推迟逻辑直接适用于商业容量的规模决策与时机选择。

## 常见错误

1. **以静态净现值作为建设规则**——忽视等待本身具有价值，在波动市场中系统性地导致过度建设。
2. **忽略派发流**——若项目在等待期间产生现金流（或其窗口期正在缩减，例如补贴到期），则 $\delta$ 较高、等待溢价较低；遗漏 $\delta$ 会高估等待溢价。
3. **期权价值一刀切**——"实物期权价值为30%"不是一个具体数字；每项灵活性都需要各自的触发条件和模型。
4. **在不适用之处使用几何布朗运动**——永续解析解假设几何布朗运动；均值回归的电价压缩了长期方差，降低等待溢价（格子模型可处理此情形）。
5. **重复计算**——在投资净现值中已纳入调度期权价值，又将其单独列为一项灵活性进行估值。

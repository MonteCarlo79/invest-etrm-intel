## 学习目标

- 定义发电资产的内在价值、逐小时内在价值以及外在（实物期权）价值。
- 从远期价差曲线计算内在价值，并明确说明其所基于的假设。
- 证明机组总价值 = 内在价值 + 外在价值，且对于免费期权而言外在价值始终非负。
- 解释为何完全预见性调度与内在价值所假设的情形*不同*——两者是方向相反的两种错误。

## 直觉理解

假设你锁定了当前的电力和燃料远期价格，并依据这些固定数值对机组进行调度：价差为正时开机，为负时停机。该计划的利润即为机组的**内在价值**——即若未来恰好与当前远期曲线所呈现的完全一致、不存在任何不确定性时，机组的价值。

实际价格会波动。灵活机组可从中获益：价差大幅扩大时多发，价差收窄时按兵不动。机组实质上持有一组关于价差的期权——而期权在波动率上升时价值*更高*。内在价值之上纯粹来源于在不确定性面前灵活运营所获得的额外价值，即**外在价值**（或实物期权价值）。以下分解关系

$$\text{机组价值} = \text{内在价值} + \text{外在价值}$$

是本模块所有机组估值的核心框架：内在价值是你今日可通过卖出远期合约对冲的部分，外在价值则只能通过出色的调度（或通过出售灵活性，例如委托加工协议）来获取。

## 正式推导

设交割小时 $t = 1..T$，电力远期价格为 $F_t$，燃料折算成本为 $K_t$（按机组热耗率折算的燃料成本加碳成本），则远期火花价差定义为 $S_t = F_t - K_t$。

**内在价值**（切换模型，按单位容量）：

$$V_{int} = \sum_t \max(S_t, 0)$$

即机组在每个远期价差为正的小时运行。**逐小时内在价值**在取最大值前，先将月度/季度远期报价细化为逐小时粒度，从而捕捉峰谷形态，但仍将曲线视为确定性的。

**外在价值。** 在价差的随机模型下，设 $\tilde S_t$ 为未来随机价差。灵活机组每小时可获得 $\mathbb{E}[\max(\tilde S_t, 0)]$，因此

$$V = \sum_t \mathbb{E}\big[\max(\tilde S_t, 0)\big] \ge \sum_t \max(\mathbb{E}[\tilde S_t], 0) = V_{int}$$

其中不等号来自 Jensen 不等式：$\max(\cdot, 0)$ 是凸函数，故不确定性*增加*了灵活机组的价值。差值 $V - V_{int}$ 即为外在价值，其随波动率、电力与燃料之间的相关结构以及到期时间的增加而增大。

**内在价值不是什么。** 内在价值固定的是*价格路径*，而非调度的先知能力。完全预见性调度——在已知当日价格的情况下对每一天重新优化——忽略了无法撤销的启动成本和约束条件，会*高估*可实现价值；而以远期价格进行静态承诺的内在价值则会*低估*它。实际运营介于两者之间：在不确定性下决策，并遵守跨时期约束。

## 计算示例

一台 1 MW（单位容量）机组，共四个交割小时，远期价差 $S = (-10, +30, -5, +50)$ 欧元/兆瓦时。

- 内在价值：$0 + 30 + 0 + 50 = 80$ 欧元/兆瓦时容量。
- 现设每小时实现价差以 50/50 概率在远期值基础上波动 ±20。各小时预期利润：第 1 小时：$(10+0)/2 = 5$；第 2 小时：$(50+10)/2 = 30$；第 3 小时：$(15+0)/2 = 7.5$；第 4 小时：$(70+30)/2 = 50$。总计 $V = 92.5$。
- 外在价值：$92.5 - 80 = 12.5$ 欧元/兆瓦时——完全由第 1 小时和第 3 小时贡献，在这两个小时中，不确定性将原本价差为负的小时转变为 50% 概率盈利的情形。已深度实值/虚值的小时从小幅对称不确定性中几乎无所获益，这正是外在价值集中于平值附近的原因。

`labs/intrinsic_vs_extrinsic_value/compute.py` 可复现该表格；测试断言内在价值为 80，总价值为 92.5，外在价值为 12.5。

## 市场变体

- **欧盟/英国：** 高比例可再生能源渗透使日内价差形态更为尖峰化，提升了灵活资产价值中外在价值的占比；清洁火花价差（含 EUA/UKA）是正确的标的。
- **美国：** 天然气价格基差波动率带来第二个外在价值来源；场外交易的热耗率看涨期权本质上就是打包的外在价值。
- **中国：** 内在/外在价值的划分对应中长期与现货的思维框架——通过中长期合约锁定的利润类似内在价值；通过现货和平衡市场捕获的剩余部分类似外在价值。由于中国现货价格存在上下限（限价），外在价值的边界与无价格上限市场有所不同。

## 常见错误

1. **将内在价值报告为"机组价值"**——这恰恰遗漏了持有实物资产而非远期头寸的价值所在（即灵活性）。
2. **完全预见性回测**——以已知价格重新优化并将结果称为可实现价值；约束条件和启动成本使得昨日的最优解无法达到。
3. **对深度实值/虚值小时叠加外在价值**——外在价值集中于平值附近；对所有小时统一施加"波动率溢价百分比"会导致重复计算。
4. **用现货价差代替远期价差计算内在价值**——内在价值定义于可交易的远期曲线；昨日的现货价差在今日无法对冲。
5. **忽略凸性的符号**——对于*必须*运行的机组（必接 PPA、热电联产），在不利状态下外在价值为负；正是灵活性使外在价值非负。

## What was built this session

Three features added to `apps/mengxi-dashboard/app.py`.

### 1. Section 8 — CSV → RDS Ingest (`with tab_data_mgmt:`)
- Scans `data/nodal/<province>/<province>_YYYY-MM.csv` files via `_scan_nodal_csvs()`
- Shows a file table; multiselect to choose files; "Ingest to RDS" button with per-file progress bar
- Calls `init_table()` + `upsert()` from `services/fengxing/nodal_price.py`
- Target table: `marketdata.md_shanxi_nodal_price_96`

### 2. "Nodal Maps" tab (`tab_nodal_maps`, tab 9)
- Province selector, date range, BESS spec (power MW, duration h, round-trip eff %)
- "Run PF Optimisation" button → queries `md_shanxi_nodal_price_96` filtered by `market_name`
- Runs `compute_dispatch_from_15min_prices()` from `services/bess_map/optimisation_engine.py` per node
- Outputs: ranked bar chart (annual rev/MW), node×month revenue heatmap, top-N investment table
- Results cached in `st.session_state["nm_last_results"]`

### 3. "PyPSA Mengxi" tab (`tab_pypsa`, tab 10)
- Graceful import check — shows `pip install pypsa>=0.28` instructions if not installed
- `pypsa>=0.28` added to `apps/mengxi-dashboard/requirements.txt`
- "Build Network" button → loads from DB: `md_rt_nodal_price`, `md_id_cleared_energy`, `ops_bess_dispatch_15min`
- Builds `pypsa.Network`: one bus per node, generators by unit_type from cleared energy, storage_units from BESS dispatch
- 5 panels: network summary metrics, avg nodal price bar chart, energy vs congestion split, 15-min price time series, BESS actual dispatch overlay

### Also done previously (same branch, already committed)

- `services/fengxing/nodal_price.py`: `filters` param added to `_post_page` / `_fetch_day`; endpoint fixed to `/api/open/v1/`

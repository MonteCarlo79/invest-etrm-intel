# 各省新能源中长期签约比例要求 (MLT Contract % Requirements)

**用途:** A2 新能源中长期义务 (interconnector tab S3) — 要求电量 = 市场交易新能源电量 × 要求比例。
**Loader format:** `- 省份: NN%` 行被 tab 的 `load_mlt_rules` 解析; 其余为文档说明。
**Sources:** Hermes KB (`staging.spot_knowledge_chunks`, probed 2026-09-14) + `data/136号文件/`. 未列省份 = 默认 80%（用户决定, tab 中标记为默认）, 待 exchange-annual-report 同步后补。

## Loader 规则行 (tab reads these)

- 蒙西: 65%
- 河南: 0%
- 山东: 0%

## 规则详情与出处

### 蒙西 (内蒙古多边交易市场)
- **新能源年度交易签约比例要求: 65%** (2025方案, 年度交易口径); 全部中长期口径 90% (燃煤 80%, 用户 80%)
- **偏差考核应签约电量 = 年度签约比例要求 × [max(上一年度上网电量, 本年度申报年度发电能力) − 本年度机制电量]** (2026蒙西中长期交易方案宣贯) — **公式明确扣除机制电量, 与 tab 的市场交易电量口径一致**
- 签约比例考核上下限: 火电/新能源统一 90–110% (2025 调整, 原 95-110/85-115 浮动带); 用户侧年度签约不超过上年用电量 80%
- 2024-04 调整: 用户中长期超额回收电量比例上限 110%→105%, 回收系数 1.05→1.1
- 跨省区优先发电计划: **年度签约比例不得低于优先发电计划的 90%** (2023年组织方案)
- 蒙西电力市场结算指引: 新能源中长期签约比例上限 115%, 超额按中长期均价与现货价差不回收负值

### 河南 (2026连续结算试运行工作方案, 2025-12-31)
- **新能源超额获利回收: 签约比例上限 110% · 下限 0% (不设下限)**, 回收倍数 1.2
- 回收触发: 签约比例低于下限 且 当月中长期均价 < 现货均价 (按中长期净合约电量含省间计)

### 山东 (新能源上网电价市场化改革实施方案, 征求意见稿-讨论版)
- **新能源中长期签约比例不设下限 (0%)**; 申报电量上限 = 额定容量 − 机制电量对应容量后的最大上网能力
- 发电侧适度放宽, 用户侧相应调整

### 广西 (2026年电力市场化交易工作事项, 征求意见)
- **用户侧中长期合同电量签约比例 ≥ 2026年实际用电量的 50%** (用户侧, 非发电侧)
- 电网代理购电: 签约比例考核 80%; 机制电量中长期合约按全体工商业用电量等比例折算纳入用户侧统计

### 福建 (现货交易实施细则 2024修订版)
- 回收机制原型: 用户侧中长期签约比例低于 λ → 缺额电量按合同均价与现货实时均价价差进行获利回收 (价差为负不启动); 发电侧比例高于上限同样回收 — **λ 具体值未见于已检索片段, 待补**

## 备注
- "不设下限"(0%) 的含义: A2 对该省要求电量为 0 → 回收敞口为 0 — 不是没有回收风险, 而是无签约比例强制; 这些省的新能源实际上"全部市场化", 外送动力与现货暴露最大。
- 蒙西 65% 为年度交易口径; 若改用全部中长期口径 (90%) 义务显著提高 — tab 输入框可覆盖。

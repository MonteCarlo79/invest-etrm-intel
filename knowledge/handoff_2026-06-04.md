## 4. Architecture reference

### Shared services
```

  pjm_knowledge/           # PJM config + Modo AI
  caiso_knowledge/         # CAISO config + Modo AI
  modo_energy/             # Modo AI API + Playwright distillation
```

### Scheduler architecture (ALL apps)
Each container starts via `run.sh` which:
1. Launches `scheduler_service.py --code {market} --app-dir apps/{market}-market` as a **background process** (8s delay)
2. Then `exec streamlit run apps/{market}-market/app.py`

**CRITICAL:** If updating any ECS task definition, keep the container command as `["/bin/bash", "apps/{market}-market/run.sh"]`, NOT `["streamlit", "run", ...]`. Reverting to direct streamlit breaks the scheduler (jobs only fire after first user page visit).

### DB schema
Primary schema for international markets: `intl_market`  
Key tables per market: `{code}_knowledge_docs`, `{code}_expert_insights`, `{code}_bess_assets`, `{code}_bess_leaderboard`, `{code}_bess_daily_index`, `{code}_bess_monthly_index`  
Shared: `intl_market.report_library`  
Spot market uses `staging` schema: `spot_knowledge_docs`, `spot_prices_hourly`, `spot_daily`

### Rebuild + redeploy pattern
```bash
# 1. ECR login
aws ecr get-login-password --region ap-southeast-1 | docker login --username AWS --password-stdin 319383842493.dkr.ecr.ap-southeast-1.amazonaws.com

# 2. Build (from bess-platform/ root, branch: cost-optimisation)
docker build -f apps/{market}-market/Dockerfile -t 319383842493.dkr.ecr.ap-southeast-1.amazonaws.com/bess-{market}-market:vNN .

# 3. Push
docker push 319383842493.dkr.ecr.ap-southeast-1.amazonaws.com/bess-{market}-market:vNN

# 4. Update terraform.tfvars image tag, then apply
cd infra/terraform && terraform apply -auto-approve -target=aws_ecs_task_definition.{market}_market -target=aws_ecs_service.{market}_market

# 5. OR force redeploy without tag change (same tag, new image content):
aws ecs update-service --cluster bess-platform-cluster --service bess-platform-{market}-market-svc --force-new-deployment --region ap-southeast-1
```

# Planka Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deploy Planka (open-source Trello clone) to ECS Fargate at `https://todo.pjh-etrm.ai` using existing RDS PostgreSQL, accessible without SSH.

**Architecture:** Planka runs as a single ECS Fargate task pulling `ghcr.io/plankanban/planka:latest`. ALB uses a host-header rule (`todo.pjh-etrm.ai`) to forward traffic directly (no Cognito). Data persists in a new `planka` database on the existing RDS instance. DNS is a manual alias record in Route53 pointing to `aws_lb.app.dns_name`.

**Tech Stack:** Terraform (HCL), Docker Compose, PostgreSQL, Planka (Node.js/Sails.js — no custom code)

- [ ] **Step 2: Create `infra/docker/postgres-init/create-multiple-dbs.sh`**

```bash
#!/bin/bash
# Creates additional databases listed in POSTGRES_MULTIPLE_DATABASES
# Format: "db1,db2,db3"
# The primary DB (POSTGRES_DB) is already created by the postgres image.

set -e

function create_db() {
  local database=$1
  echo "Creating database '$database'"
  psql -v ON_ERROR_STOP=1 --username "$POSTGRES_USER" <<-EOSQL
    CREATE DATABASE $database;
EOSQL
}

if [ -n "$POSTGRES_MULTIPLE_DATABASES" ]; then
  echo "Multiple database creation requested: $POSTGRES_MULTIPLE_DATABASES"
  for db in $(echo $POSTGRES_MULTIPLE_DATABASES | tr ',' ' '); do
    create_db $db
  done
  echo "Multiple databases created"
fi
```

- [ ] **Step 3: Make it executable**

```bash

```

- [ ] **Step 4: Update `docker-compose.yml` — add volumes and env to postgres service**

# PLANKA TASK
# Personal Kanban board. No custom image — pulls from ghcr.io directly.
# 256/512 is generous for a single-user Planka instance.

resource "aws_ecs_task_definition" "planka" {
  family                   = "${var.name}-planka"
  requires_compatibilities = ["FARGATE"]
  network_mode             = "awsvpc"
  cpu                      = "256"
  memory                   = "512"

  execution_role_arn = aws_iam_role.task_execution.arn
  task_role_arn      = aws_iam_role.task_role.arn

  container_definitions = jsonencode([
    {
      name      = "planka"
      image     = "ghcr.io/plankanban/planka:latest"
      essential = true

      portMappings = [
        {
          containerPort = 1337
          protocol      = "tcp"
        }
      ]

      environment = [
        {
          name  = "DATABASE_URL"
          value = "postgresql://${var.db_username}:${var.db_password}@${aws_db_instance.pg.address}:5432/planka?sslmode=require"
        },
        {
          name  = "SECRET_KEY"
          value = var.planka_secret_key
        },
        {
          name  = "BASE_URL"
          value = var.planka_base_url
        },
        {
          name  = "DEFAULT_ADMIN_EMAIL"

        {
          name  = "DEFAULT_ADMIN_PASSWORD"
          value = var.planka_admin_password
        },
        {
          name  = "TRUST_PROXY"

        logDriver = "awslogs"

### Task 6: Pre-deploy — create `planka` database on RDS

**Files:** None

- [ ] **Step 1: Get RDS endpoint from Terraform state**

```bash
cd infra/terraform
terraform output -raw db_endpoint 2>/dev/null || \
  terraform state show aws_db_instance.pg | grep address
```

Note the RDS hostname (format: `bess-platform-xxx.xxx.ap-southeast-1.rds.amazonaws.com`).

- [ ] **Step 2: Run psql via ECS exec or a one-off task**

The easiest approach is to use an existing ECS task that has RDS access. Run a one-off psql command using the AWS CLI to exec into a running container, or use a bastion pattern. The simplest: use the uploader container which already has psql available.

```bash
# Get a running uploader task ARN
TASK_ARN=$(aws ecs list-tasks \
  --cluster bess-platform \
  --service-name bess-platform-uploader-svc \
  --region ap-southeast-1 \
  --query 'taskArns[0]' --output text)

# Exec into it and create the DB
aws ecs execute-command \
  --cluster bess-platform \
  --task "$TASK_ARN" \
  --container bess-uploader \
  --command "psql \$PGURL -c 'CREATE DATABASE planka;'" \
  --interactive \
  --region ap-southeast-1
```

Expected output: `CREATE DATABASE`

If ECS exec is not enabled on the uploader service, use a local psql with the RDS credentials from `terraform.tfvars`, tunnelled through an EC2 bastion or SSM port-forward.

- [ ] **Step 3: Verify DB exists**

```bash
aws ecs execute-command \
  --cluster bess-platform \
  --task "$TASK_ARN" \
  --container bess-uploader \
  --command "psql \$PGURL -c '\l planka'" \
  --interactive \
  --region ap-southeast-1
```

Expected: row showing `planka` database.

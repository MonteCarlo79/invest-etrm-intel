# Asset-Backed Trading — Generative Investment Scout (Plan 3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the generative investment scout (spec §5.9): deterministic opportunity scans → grounded LLM thesis cards → validation against realized monetization → a review queue on the 价值筛选 tab with promote-to-deal-brief. The machine proposes; the desk disposes.

**Architecture:** `services/option_engine/scout/` package — `store.py` (cards table + review actions), `scans_trading.py` / `scans_investment.py` (deterministic candidate generators), `thesis.py` (LLM card drafting, delta-gated), `validate.py` (realized-evidence verdicts), `scout.py` (orchestrator) + `run_scout.py` CLI. UI lands in `apps/deal_structurer/screen_tab.py` (review queue section) + the deferred 4th agent tool `list_opportunity_cards`.

**Tech Stack:** Python, pandas, SQLAlchemy, shared/anthropic_client (claude-sonnet-4-6, usage-metered), Streamlit (queue UI), pytest.

**Spec:** `docs/superpowers/specs/2026-10-24-asset-backed-trading-design.md` §5.9 (+ §11.12–14 rulings) — read it first.

## Global Constraints

- **Branch:** `feat/abt-scout` from main. Pathspec-scoped commits, trailer `Co-Authored-By: Claude Code <noreply@anthropic.com>`. Push at plan end (finishing flow).
- **Cadence (user call, spec §11.15):** investment scans monthly, trading scans weekly, LLM thesis drafting **delta-gated** (skip unchanged candidates — the cost lever). v1 runs manual/CLI; no EventBridge/terraform in this plan.
- **Grounding (hard):** thesis text generated ONLY from the candidate's evidence pack; every number in a card must trace to it. The LLM never invents candidates.
- **Write allowlist (hard):** scout code writes ONLY to `marketdata.option_opportunity_cards`, plus `deal_briefs` on user-clicked promote, plus `agent_memory` (app='deal_scout') on review decisions. No other production writes. Scans are SELECT-only.
- **Honesty:** a card with no comparable realized evidence gets `validation='no_evidence'` — never a fabricated anchor. Wind/solar screen-grade caveat rides the card.
- **No real LLM/DB in unit tests** — mock `make_client`; engine via fakes/stubs. Integration runs marked `skipif(not os.environ.get("PGURL"))`.
- **Chinese for user-facing card text** (thesis, verdict labels); English for code/identifiers.
- Test runner: `~/.venvs/bess-platform/bin/python -m pytest tests/option_engine/ tests/deal_structurer/ -v`
- Reuse, don't rebuild: `apps.deal_structurer.screen_tab` helpers (import-safe, proven), `services.deal_committee.brief.parse_brief_json` + `library.save_brief` (promotion), `services.deal_committee.economics._register_comp_rate` (empirical comp rates), `shared/anthropic_client.make_client` + `shared/usage_meter.usage_tag`.

## Review Focus

1. **Delta-gating is the cost control** (spec §5.9: ~70-80% of LLM calls eliminated in steady state) — a broken dedup silently multiplies LLM spend weekly. Pin: same-signature candidate with evidence numbers within 5% → no LLM call, card marked "carried".
2. **Z-scores on thin history** — a province with 35 days of data produces meaningless regime shifts. Every scan guards minimum history (≥120 days) with skip + reason.
3. **Province-name variants across tables** （河北南网/冀南， 蒙西/内蒙古（蒙西）) silently drop rows in joins. Pin: scans route province names through one mapping helper (extend the `CAP_COMP_NAME_MAP` pattern; test both directions).
4. **Promotion must produce a valid DealBrief** — `parse_brief_json` round-trip, `confirmed=False`, committee flow unbroken. Pin the round-trip test.
5. **Validator never fabricates** — no comparable data → `no_evidence`; a register-unsupported province is not an error. Pin the test.
